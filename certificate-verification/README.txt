GETI Certificate Verification deployment
1. Upload certificate-verification/index.html to public_html/certificate-verification/index.html
2. Confirm https://getienglish.com/certificate-verification/ responds HTTP 200 and can load GETI registry API.
3. Add certificate-verification URL to existing XML sitemap (do not replace existing sitemap).
4. Link to this page from home / certificates / navigation.
5. Request indexing through Google Search Console URL Inspection.
6. Do not publish private certificate personal data for general Google indexing.
Google rankings and indexing are not guaranteed.
