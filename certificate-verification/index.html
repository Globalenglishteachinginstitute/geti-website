GETI Certificate Verification — Frequently Asked Questions

How can I verify a GETI certificate online?

Enter the Certificate ID or certificate holder's name in the search form above and select Verify Certificate. The page checks the available records through the GETI verification service.

Can I verify a GETI TEFL or TESOL certificate with a QR code?

Yes, when the certificate contains a supported GETI QR code. Use Scan QR Code, grant camera access on HTTPS or upload a clear QR image. The code identifies a record to look up; the registry result determines whether a matching record is found.

What if a GETI certificate is not found?

Check the spelling and Certificate ID carefully, then try again. If no record is returned, or the service is unavailable, contact certificate@getienglish.com. A missing result should not automatically be treated as proof of fraud.

Is a verified GETI certificate the same as external accreditation?

No. This page checks records held by GETI. Recognition or accreditation by an external body is a separate question. Read the GETI recognition information and verify any third-party status independently.
