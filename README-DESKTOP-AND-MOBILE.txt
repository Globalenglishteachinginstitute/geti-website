GETI — MOBILE + DESKTOP PWA
===========================

This package keeps the SAME GETI website and functions.

Nothing is removed:
- Student Area
- Login
- Exams
- My Result
- Messages
- Certificate Verification
- Library
- Existing Supabase functions
- Mobile PWA support

DESKTOP / WINDOWS
-----------------
After the files are published on getienglish.com:

Microsoft Edge:
1. Open https://getienglish.com/
2. Menu (...) > Apps > Install GETI
3. Allow Start menu / taskbar / desktop shortcut if offered.

Google Chrome:
1. Open https://getienglish.com/
2. Use the Install icon in the address bar, or Menu > Install GETI
3. GETI opens in its own standalone window like desktop software.

ANDROID
-------
The existing mobile PWA remains available.
Open https://getienglish.com/ in Chrome and choose Install app / Add to Home screen.

IMPORTANT
---------
Upload ALL files in this package to the same GitHub Pages root.
Do not delete the existing mobile PWA files.
The same PWA supports both phone and computer.
