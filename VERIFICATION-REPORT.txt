Security corrections included:

   Google Sheet administration now goes only through authenticated GETI admin backend sheet_proxy.
2. Removed client-side code:"global" from Google Sheet calls.
3. Added safe JavaScript argument encoding for dynamic admin action buttons,
   preventing names/emails with apostrophes or special characters from breaking handlers.

Remaining architecture note:
- Admin token is stored in localStorage by the current backend design.
  Stronger future security would use a Secure + HttpOnly server session cookie.
  This cannot be changed safely from HTML alone without updating the backend.
